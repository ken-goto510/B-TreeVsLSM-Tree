MySQL Index Benchmark

InnoDB — B-tree  vs  MyRocks — SSTable / LSM-tree

InnoDB — B-tree Index

  • 全データをB+ツリーで管理（クラスタードインデックス）
  • 主キー検索: O(log N) で安定
  • 範囲スキャン: リーフノードのリンクリストで効率的
  • 書込み: ページを直接更新（Write-in-place）
  • 読込み多・更新少ワークロードに強い

MyRocks — SSTable / LSM-tree

  • 書込みはまずメモリ(MemTable)へ → 定期的にSSTable(不変ファイル)にflush
  • バックグラウンドCompactionでSSTableをマージ
  • 書込みが速く、書込みアンプリフィケーションが低い
  • 読込みは複数SSTableを確認（読込みアンプリフィケーション）
  • 書込み多・圧縮重視ワークロードに強い
